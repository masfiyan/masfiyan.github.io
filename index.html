What I can do for you

Start from the problem, then build the Odoo that solves it.

Standard Odoo covers a lot. When it doesn't match your process, I configure what exists first and write custom modules only for the real gaps.

"Production doesn't match the system."

Manufacturing (MRP)

I map your production flow into Odoo, from raw material procurement through work orders and quality checks to finished-goods receipt.

  • Multi-level BoMs
  • Work centers
  • Routings
  • Production planning
"Stock in Odoo is never right."

Inventory & warehouses

I set up multi-warehouse operations with the right routes and rules, and build custom transfer flows, validations and reports where you need them.

  • Push/pull rules
  • Reordering
  • Lot/serial tracking
  • Stock valuation
"Our stores need more than standard POS."

Point of Sale

I build custom POS features for multi-store retail, such as discount rules, OTP validation and payment gateway integration, on both the front end and the backend.

  • OWL / JavaScript
  • Discount logic
  • OTP validation
  • Payments
"We type the same data into two systems."

Integrations & webhooks

I connect Odoo to payment, delivery and third-party systems through REST APIs and webhooks, so data moves automatically and failures are visible.

  • REST APIs
  • Webhooks
  • Shipment tracking
  • Refund automation
"Payroll still lives in a spreadsheet."

Payroll

I set up salary structures and rules that reflect your contracts, allowances and deductions, with payslip reports that your HR team can trust.

  • Salary structures
  • Salary rules
  • Contracts
  • Payslip reports

Reports, access & automation

I build custom QWeb reports, set up security groups and record rules, and automate repetitive work with server actions and scheduled jobs.

  • Cron jobs
